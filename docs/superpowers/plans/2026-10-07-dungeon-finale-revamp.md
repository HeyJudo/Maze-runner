# Level 4 Revamp (Forgotten Keep) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Level 4 with a dense 46×46 sprite-based dungeon: explore three wings for keys K, Q, V; taking V starts a collapse that you escape back to the entrance.

**Architecture:** Gameplay stays in pure engine classes (`DungeonRun`, new `Collapse`) driven by the 16 ms tick. Rendering reads that state: walls auto-tile from a sprite atlas into the existing static cache, and a live layer draws traps, the collapse and a low-res light map each frame. The level is generated by a committed Python script, then validated in VB before play.

**Tech Stack:** VB.NET (.NET 10, WinForms + GDI+), System.Text.Json, Python 3 + Pillow for offline tools only.

**Spec:** `docs/superpowers/specs/2026-10-07-dungeon-finale-revamp-design.md` (read it before any task).

## Global Constraints

- VB files start with `Option Strict On` / `Option Explicit On`; match surrounding style (short comments, `Namespace Engine|Levels|Rendering|UI`).
- No new NuGet packages. Python tools may use Pillow; the game never runs Python.
- Tick = 16 ms; marble top speed 0.12 tiles/tick. Do not change `GameEngine` physics constants.
- Collapse numbers: `RumbleMs` 4000, `Speed` 3.0 tiles/s, `Pushback` 8 tiles, cave-in warning 1500 ms, crack band 2 tiles. Crumble: pit 800 ms after contact, re-forms 6000 ms later.
- Level size 46×46 (31×31 source widened by the `tools/widen_maze.py` rule).
- Damage unchanged: trap 1 heart, wall ¼ heart, pit/lava/crumble/front 1 heart (ignores protection like pits do).
- Sprites draw with `InterpolationMode.NearestNeighbor` + `PixelOffsetMode.Half`, restoring the previous modes afterwards.
- Tile chars: existing `0 1 S G H L T`; dungeon `K Q V c E T C W`. `a`/`b` are retired and must be rejected.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Check command (repo root): `dotnet run --project tools/DungeonChecks/DungeonChecks.vbproj -c Release`. Game build: `dotnet build GravityMaze/GravityMaze.vbproj -c Release`.

## Review Focus

1. **Respawn into danger:** after a front catch or pit the marble must land on a tile that is not collapsed, rubble or a pit. Otherwise it falls forever. Pinned in Task 4 (`Caught` keeps ≥ 8 tiles) and Task 5 (engine respawn test).
2. **Pause mid-collapse:** pausing during the rumble or a cave-in warning must freeze the collapse clock. Pinned in Task 10 (TransitionChecks asserts `Collapse.ElapsedMs` is unchanged while paused).
3. **Parking on a cave-in:** a cave-in waits while occupied, then closes once the marble leaves. Pinned in Task 4.
4. **Restart mid-escape:** R must reset keys, gates, collapse, checkpoints and crumble. Pinned in Task 5.
5. **Checkpoint skip exploit:** escape checkpoints lit while exploring must not teleport the marble ahead during the escape. Escape checkpoints only light after collapse, explore checkpoints only before. Pinned in Task 5.

```vb
Public Function EscapeOpen(maze As MazeDefinition, row As Integer, column As Integer) As Boolean
    If row < 0 OrElse column < 0 OrElse row >= maze.RowCount OrElse column >= maze.ColumnCount Then Return False
    Select Case maze.GetTile(row, column)
        Case "1"c : Return IsBreakaway(maze, row, column)
        Case "H"c, "W"c, "C"c, "c"c : Return False
        Case Else : Return True
    End Select
End Function
```

```vb
Option Strict On
Option Explicit On

Imports System
Imports System.Collections.Generic
Imports System.Drawing
Imports System.IO
Imports System.Text.Json

Namespace Levels
    Public NotInheritable Class AtlasSprite
        Public Property Sheet As String = ""
        Public Property X As Integer
        Public Property Y As Integer
        Public Property W As Integer
        Public Property H As Integer
        Public Property Frames As Integer = 1
    End Class

    ' Name -> rectangle map for the dungeon sheets. Frames sit left to right, each W wide.
    Public NotInheritable Class SpriteAtlas
        Public Shared ReadOnly Sheets As String() = {"dungeon", "freed", "maze", "extra"}
        Public Shared ReadOnly RequiredNames As String() = (
            "floor_0 floor_1 floor_2 floor_3 wall_top wall_face wall_edge_n wall_edge_e wall_edge_s wall_edge_w " &
            "wall_inner_ne wall_inner_nw wall_inner_se wall_inner_sw gate_closed gate_open door_wood arch_open arch_pillars " &
            "torch chains banner gold_pile gold_coins gold_stack chest pot skull bones keg pedestal iron_ball table chair " &
            "rack_swords rack_spears spikes saw arrow crumble lava pit rubble key blood").Split(" "c)
        Private ReadOnly sprites As Dictionary(Of String, AtlasSprite)

        Private Sub New(sprites As Dictionary(Of String, AtlasSprite))
            Me.sprites = sprites
        End Sub

        Public Shared Function Load(path As String) As SpriteAtlas
            Dim options As New JsonSerializerOptions With {.PropertyNameCaseInsensitive = True}
            Dim map = JsonSerializer.Deserialize(Of Dictionary(Of String, AtlasSprite))(File.ReadAllText(path), options)
            If map Is Nothing Then Throw New InvalidDataException("Atlas is empty: " & path)
            Return New SpriteAtlas(map)
        End Function

        Public Function Has(name As String) As Boolean
            Return sprites.ContainsKey(name)
        End Function

        Default Public ReadOnly Property Item(name As String) As AtlasSprite
            Get
                Return sprites(name)
            End Get
        End Property

        Public Sub Validate(sheetSize As Func(Of String, Size))
            For Each pair In sprites
                Dim s = pair.Value
                If s Is Nothing OrElse Array.IndexOf(Sheets, s.Sheet) < 0 OrElse s.W <= 0 OrElse s.H <= 0 OrElse s.Frames < 1 OrElse s.X < 0 OrElse s.Y < 0 Then
                    Throw New InvalidDataException("Bad atlas entry " & pair.Key)
                End If
                Dim size = sheetSize(s.Sheet)
                If s.X + s.W * s.Frames > size.Width OrElse s.Y + s.H > size.Height Then Throw New InvalidDataException("Atlas entry outside its sheet: " & pair.Key)
            Next
        End Sub

        ' PNG width/height live big-endian at bytes 16-23 of the IHDR chunk.
        Public Shared Function PngSize(path As String) As Size
            Dim b = New Byte(23) {}
            Using f = File.OpenRead(path)
                If f.Read(b, 0, 24) <> 24 Then Throw New InvalidDataException("Not a PNG: " & path)
            End Using
            Return New Size(b(16) << 24 Or b(17) << 16 Or b(18) << 8 Or b(19), b(20) << 24 Or b(21) << 16 Or b(22) << 8 Or b(23))
        End Function
    End Class
End Namespace
```

```vb
Option Strict On
Option Explicit On

Imports System
Imports System.Collections.Generic
Imports System.Drawing
Imports System.Linq
Imports GravityMaze.Levels

Namespace Engine
    ' The escape after the vault key: a crumbling front that follows corridors outward from the vault,
    ' plus warned cave-ins. Pure tile logic; DungeonRun drives it and renderers only read it.
    Public NotInheritable Class Collapse
        Public Const CaveWarningMs As Integer = 1500
        Public Const CrackBand As Single = 2.0F
        Public Const Pending As Integer = 0, Warning As Integer = 1, Closed As Integer = 2

        Private ReadOnly spec As CollapseSpec
        Private ReadOnly rows As Integer, columns As Integer
        Private ReadOnly dist As Integer(,)
        Private ReadOnly states As Integer()
        Private ReadOnly warnedAt As Long()
        Private ReadOnly caveOf As New Dictionary(Of Integer, Integer)()   ' tile key -> cave-in index
        Private clock As Long
        Private push As Single
        Private changes As Integer

        ' passable(row, column) describes the map once the collapse starts, before any cave-in closes.
        ' Every cave-in tile counts as wall here, so the front never shortcuts through one.
        Public Sub New(spec As CollapseSpec, rows As Integer, columns As Integer, origin As Point, passable As Func(Of Integer, Integer, Boolean))
            Me.spec = spec : Me.rows = rows : Me.columns = columns
            states = New Integer(spec.CaveIns.Count - 1) {}
            warnedAt = New Long(spec.CaveIns.Count - 1) {}
            For i As Integer = 0 To spec.CaveIns.Count - 1
                For Each t In spec.CaveIns(i).Tiles
                    caveOf(t.Row * columns + t.Column) = i
                Next
            Next
            dist = New Integer(rows - 1, columns - 1) {}
            For r As Integer = 0 To rows - 1
                For c As Integer = 0 To columns - 1
                    dist(r, c) = -1
                Next
            Next
            Dim queue As New Queue(Of Point)()
            dist(origin.Y, origin.X) = 0
            queue.Enqueue(origin)
            While queue.Count > 0
                Dim p = queue.Dequeue()
                For Each d In {New Point(1, 0), New Point(-1, 0), New Point(0, 1), New Point(0, -1)}
                    Dim x = p.X + d.X, y = p.Y + d.Y
                    If x < 0 OrElse y < 0 OrElse x >= columns OrElse y >= rows OrElse dist(y, x) >= 0 Then Continue For
                    If Not passable(y, x) OrElse caveOf.ContainsKey(y * columns + x) Then Continue For
                    dist(y, x) = dist(p.Y, p.X) + 1
                    queue.Enqueue(New Point(x, y))
                Next
            End While
        End Sub

        Public ReadOnly Property ElapsedMs As Long
            Get
                Return clock
            End Get
        End Property

        Public ReadOnly Property Rumbling As Boolean
            Get
                Return clock < spec.RumbleMs
            End Get
        End Property

        ' Walking tiles from the vault that have fallen; negative during the rumble.
        Public ReadOnly Property Reach As Single
            Get
                Return spec.Speed * (clock - spec.RumbleMs) / 1000.0F - push
            End Get
        End Property

        ' Bumps whenever a cave-in changes state, so planners know to re-route.
        Public ReadOnly Property Version As Integer
            Get
                Return changes
            End Get
        End Property

        Public Function Distance(row As Integer, column As Integer) As Integer
            If row < 0 OrElse column < 0 OrElse row >= rows OrElse column >= columns Then Return -1
            Return dist(row, column)
        End Function

        Public Function IsCollapsed(row As Integer, column As Integer) As Boolean
            Dim d = Distance(row, column)
            Return d >= 0 AndAlso d < Reach
        End Function

        Public Function IsCracking(row As Integer, column As Integer) As Boolean
            Dim d = Distance(row, column)
            Return d >= 0 AndAlso d >= Reach AndAlso d < Reach + CrackBand
        End Function

        Public Function CaveInState(index As Integer) As Integer
            Return states(index)
        End Function

        Public Function IsRubble(row As Integer, column As Integer) As Boolean
            Dim index As Integer
            Return caveOf.TryGetValue(row * columns + column, index) AndAlso states(index) = Closed
        End Function

        Public Function IsCaveInWarning(row As Integer, column As Integer) As Boolean
            Dim index As Integer
            Return caveOf.TryGetValue(row * columns + column, index) AndAlso states(index) = Warning
        End Function

        Public Sub Advance(ms As Integer, occupied As Func(Of Integer, Integer, Boolean))
            clock += ms
            For i As Integer = 0 To states.Length - 1
                Dim cave = spec.CaveIns(i)
                If states(i) = Pending AndAlso Reach >= cave.AtReach Then
                    states(i) = Warning : warnedAt(i) = clock : changes += 1
                End If
                If states(i) = Warning AndAlso clock - warnedAt(i) >= CaveWarningMs AndAlso
                   Not cave.Tiles.Any(Function(t) occupied(t.Row, t.Column)) Then
                    states(i) = Closed : changes += 1
                End If
            Next
        End Sub

        ' After a catch or fall the front must sit at least Pushback tiles behind the respawn tile.
        Public Sub Caught(respawnRow As Integer, respawnColumn As Integer)
            Dim d = Distance(respawnRow, respawnColumn)
            Dim target = If(d < 0, Reach - spec.Pushback, Math.Min(Reach - spec.Pushback, d - spec.Pushback))
            push += Reach - target
        End Sub
    End Class
End Namespace
```

```vb
Private Shared Sub DrawDarkness(g As Graphics, left As Single, top As Single, tile As Single, maze As MazeDefinition, run As DungeonRun)
    Dim w = maze.ColumnCount * LightScale, h = maze.RowCount * LightScale
    If _light Is Nothing OrElse _light.Width <> w OrElse _light.Height <> h Then

        Next

        ' Keys, lava and lit checkpoints glow too: radius 1.5 / 1.2 / 2.5 at intensity 0.8.
    End Using
    ' Brightness -> darkness alpha: A = Darkness * (1 - R); colour is a deep purple.

        New Single() {0, 0, 0, 0, 0},
        New Single() {0, 0, 0, 0, 0},
        New Single() {0, 0, 0, 0, 0},
        New Single() {0.03F, 0.02F, 0.06F, Darkness, 1}})

        g.InterpolationMode = Drawing2D.InterpolationMode.Bilinear
        g.DrawImage(_light, Rectangle.Round(New RectangleF(left, top, maze.ColumnCount * tile, maze.RowCount * tile)),

End Sub

        Using brush As New Drawing2D.PathGradientBrush(path)
            brush.CenterColor = Color.FromArgb(CInt(255 * intensity), 255, 255, 255)
```

```vb
Imports System
Imports System.Drawing
Imports System.IO
Imports GravityMaze.Engine

Public Module ProofChecks
    Public Sub Run()
        Dim maze = MazeManager.LoadFromFile(Path.Combine(AppContext.BaseDirectory, "Mazes", "Level4.txt"))
        For Each delay In {0, 37, 125, 250}
            Dim engine As New GameEngine(maze, 0)
            For i As Integer = 1 To delay : engine.Update(0, 0) : Next
            Dim pilot As New DungeonPilot(maze)
            Dim tilt = PointF.Empty
            Dim hits = 0, escapeStart = -1.0F, caught = 0
            AddHandler engine.HeartLost, Sub(s, e) hits += 1
            AddHandler engine.BallFell, Sub(s, e) If engine.Dungeon.Collapse IsNot Nothing Then caught += 1
            For tick As Integer = 1 To 60000
                tilt = DungeonPilot.Smooth(tilt, pilot.NextTilt(engine))
                engine.Update(tilt.X, tilt.Y)
                If escapeStart < 0 AndAlso engine.Dungeon.Collapse IsNot Nothing Then escapeStart = engine.ElapsedSeconds
                If engine.State <> GameState.Playing Then Exit For
            Next
            Check(engine.State = GameState.LevelComplete AndAlso engine.Hearts >= 1, $"Keep must be beatable on board-smoothed tilt (delay {delay})")
            Dim escape = engine.ElapsedSeconds - escapeStart
            Check(escape >= 25 AndAlso escape <= 70, $"Escape should take 25-70 s, took {escape:F1}")
            Console.WriteLine($"CLEAR: delay={delay * 16}ms total={engine.ElapsedSeconds:F1}s escape={escape:F1}s hearts={engine.Hearts:F2} hits={hits} caught={caught} waited={pilot.WaitTicks}")
        Next
    End Sub
End Module
```
